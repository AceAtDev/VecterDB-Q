Quick Start Guide:
1. Create a new library from the Libraries page
2. Add document chunks from the Documents page
3. Search your documents from the Search page

⚠️ Important: All documents in a library must use the same embedding model (the server's embedding model: Cohere embed-english-light-v3.0 or local all-MiniLM-L6-v2, both 384 dimensions).

🎯 Understanding Search Scores:
• 🔥 90-100% = Excellent match (very similar meaning)
• ✨ 70-89% = Good match (related concepts)
• ⚡ 50-69% = Fair match (somewhat related)
• 💭 <50% = Weak match (different topics)
